# Developer Keys

> Canvas LMS REST API — `/developer_keys` resource. Base path `/api`.

## GET /v1/accounts/{account_id}/developer_keys

**List Developer Keys**  —  `list_developer_keys`

List all developer keys created in the current account.

| Param | Type | In | Req | Description |
| --- | --- | --- | --- | --- |
| `account_id` | string | path | yes | ID |
| `inherited` | boolean | query |  | Defaults to false. If true, lists keys inherited from Site Admin (and consortium parent account, if applicable). |

**Returns:** `array[DeveloperKey]`

## POST /v1/accounts/{account_id}/developer_keys

**Create a Developer Key**  —  `create_developer_key`

Create a new Canvas API key. Creating an LTI 1.3 registration is not supported here and
should be done via the LTI Registration API.

| Param | Type | In | Req | Description |
| --- | --- | --- | --- | --- |
| `account_id` | string | path | yes | ID |
| `developer_key` | json | form | yes | no description |
| `developer_key[auto_expire_tokens]` | boolean | form |  | Defaults to false. If true, access tokens generated by this key will expire after 1 hour. |
| `developer_key[email]` | string | form |  | Contact email for the key. |
| `developer_key[icon_url]` | string | form |  | URL for a small icon to display in key list. |
| `developer_key[name]` | string | form |  | The display name. |
| `developer_key[notes]` | string | form |  | User-provided notes about the key. |
| `developer_key[redirect_uri]` | string | form |  | Deprecated in favor of redirect_uris. Do not use. |
| `developer_key[redirect_uris]` | array | form |  | List of URLs used during OAuth2 flow to validate given redirect URI. |
| `developer_key[vendor_code]` | string | form |  | User-specified code representing the vendor that uses the key. |
| `developer_key[visible]` | boolean | form |  | Defaults to true. If false, key will not be visible in the UI. |
| `developer_key[test_cluster_only]` | boolean | form |  | Defaults to false. If true, key is only usable in non-production environments (test, beta). Avoids problems with beta refresh. |
| `developer_key[client_credentials_audience]` | string | form |  | Used in OAuth2 client credentials flow to specify the audience for the access token. |
| `developer_key[scopes]` | array | form |  | List of API endpoints key is allowed to access. |
| `developer_key[require_scopes]` | boolean | form |  | If true, then token requests with this key must include scopes. |
| `developer_key[allow_includes]` | boolean | form |  | If true, allows `includes` parameters in API requests that match the scopes of this key. |

**Returns:** `DeveloperKey`

# Models


## DeveloperKey

a Canvas API key (or LTI 1.3 registration)

| Property | Type | Req | Description |
| --- | --- | --- | --- |
| `id` | integer |  | The Canvas ID of the DeveloperKey object e.g. `1` |
| `name` | string |  | The display name e.g. `Test Key` |
| `created_at` | datetime |  | Timestamp of the key's creation e.g. `2025-05-30T17:09:18Z` |
| `updated_at` | datetime |  | Timestamp of the key's last update e.g. `2025-05-30T17:09:18Z` |
| `workflow_state` | string |  | The state of the key e.g. `active` Allowed: `active`, `deleted` |
| `is_lti_key` | boolean |  | True if key represents an LTI 1.3 Registration. False for Canvas API keys e.g. `False` |
| `email` | string |  | Contact email configured for key e.g. `test@example.com` |
| `icon_url` | string |  | URL for a small icon to display in key list e.g. `https://example.com/icon.png` |
| `notes` | string |  | User-provided notes about key e.g. `this key is for testing` |
| `vendor_code` | string |  | User-specified code representing the vendor that uses the key e.g. `Google` |
| `account_name` | string |  | The name of the account that owns the key e.g. `Test Account` |
| `visible` | boolean |  | True for all keys except Site Admin-level keys, which default to false. Controls visibility in the Inherited tab. e.g. `True` |
| `scopes` | array[string] |  | List of API endpoints key is allowed to access (API keys), or LTI 1.3 scopes (LTI keys) e.g. `['url:GET\|/api/v1/accounts']` |
| `redirect_uri` | string |  | Deprecated in favor of redirect_uris. Do not use. e.g. `no` |
| `redirect_uris` | array[string] |  | List of URLs used during OAuth2 flow to validate given redirect URI (API keys), or to redirect to after login (LTI keys) e.g. `['https://mytool.com/oauth2/redirect', 'https://mytool.com/1_3/launch']` |
| `access_token_count` | integer |  | (API keys only) The number of active access tokens associated with the key e.g. `42` |
| `last_used_at` | datetime |  | (API keys only) The last time an access token for this key was used in an API request e.g. `2025-05-30T17:09:18Z` |
| `test_cluster_only` | boolean |  | (API keys only) If true, key is only usable in non-production environments (test, beta). Avoids problems with beta refresh. e.g. `False` |
| `allow_includes` | boolean |  | (API keys only) If true, allows `includes` parameters in API requests that match the scopes of this key e.g. `True` |
| `require_scopes` | boolean |  | (API keys only) If true, then token requests with this key must include scopes e.g. `False` |
| `client_credentials_audience` | string |  | (API keys only) Used in OAuth2 client credentials flow to specify the audience for the access token e.g. `external` |
| `api_key` | string |  | (API keys only) The client secret used in the OAuth authorization_code flow. e.g. `sd45fg64....` |
| `tool_configuration` | Lti::ToolConfiguration |  | (LTI keys only) The Canvas-style tool configuration for this key. e.g. `{'type': 'Lti::ToolConfiguration'}` |
| `public_jwk` | object |  | (LTI keys only) The tool's public JWK in JSON format. Discouraged in favor of a url hosting a JWK set. e.g. `{'e': 'AQAB', 'etc': 'etc'}` |
| `public_jwk_url` | string |  | (LTI keys only) The tool-hosted URL containing its public JWK keyset. Canvas may cache JWKs up to 5 minutes. e.g. `https://mytool.com/1_3/jwks` |
| `lti_registration` | object |  | (LTI keys only) The LTI IMS Registration object for this key, if key was created via Dynamic Registration. e.g. `{'type': 'TODO Lti::IMS::Registration'}` |
| `is_lti_registration` | boolean |  | (LTI keys only) Returns true if key was created via Dynamic Registration. e.g. `False` |
| `user_name` | string |  | Unused. |
| `user_id` | string |  | Unused. |
| `unified_tool_id` | string |  | Correlates an API key to a product configuration. e.g. `6ba7b810-9dad-11d1-80b4-00c04fd430c8` |
